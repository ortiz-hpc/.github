# Ortiz HPC Guidelines 📐

> **Engineering Methodology & Theoretical Roadmap**  
> *Core standards, mathematical prerequisites, physical domains, and execution pipelines governing all proofs of concept (PoCs) within the Ortiz HPC ecosystem.*

---

## 📌 Overview

This directory acts as the centralized knowledge base and operational manifesto for the **Ortiz HPC** organization. To maintain rigorous engineering standards, every computational project follows a strict methodological pipeline from physical modeling to low-level hardware optimization.

---

## 📂 Structure

- [`strategy.md`](./strategy.md) — **The Execution Pipeline:** The systematic workflow from real-world problems to optimized hardware execution.
- [`math.md`](./math.md) — **Mathematical Roadmap:** Essential applied mathematics, numerical methods, and linear algebra required for high-performance simulation.
- [`physics.md`](./physics.md) — **Physical Domains:** Governing differential equations and core physical phenomena (heat transfer, fluid dynamics, porous media).

---

## ⚙️ Core Philosophy

1. **First-Principles Engineering:** No black-box frameworks or hidden abstractions. Every numerical engine is built from scratch.
2. **Hardware Awareness:** Designing algorithms around memory hierarchy, cache locality, and vectorization limits.
3. **Global Standard:** 100% of documentation, code, and technical notes are written in English to align with international high-performance computing standards.
